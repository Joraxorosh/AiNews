# AI News

Агрегатор новостей IT и ИИ с базой знаний. Это статический сайт на GitHub Pages, а новости раз в 3 часа собирает GitHub Actions.

**Вкладки:** Лента · Дайджест · Модели ИИ · Инструменты · Наука · IT и безопасность · Избранное · База знаний · Оформление

## Как устроено

```
sources.json              список RSS/Atom-источников (категория, лимит записей)
scripts/fetch_news.py     сборщик: стандартная библиотека Python 3.11+, без зависимостей
site/                     сам сайт (HTML/CSS/JS без сборки)
  data/news.json          собранные новости (генерируется, история за 45 дней)
  data/kb.json            база знаний (заполняется вручную)
.github/workflows/update.yml   cron: сбор → коммит news.json → деплой на Pages
```

Новости автоматически получают теги по ключевым словам: модель, релиз, безопасность, баг/сбой, open source, агенты, API/цены, исследование.
**Дубли склеиваются:** если одну новость пишут несколько источников, в ленте будет одна карточка с пометкой «N источников» и ссылками «Также: …». Сборщик сравнивает заголовки по доле общих слов (порог `DEDUP_JACCARD` в `fetch_news.py`) и помечает такие записи общим полем `group`. Ленты одного сайта (`family` в `sources.json`) считаются одним источником.

**Дайджест** — главное за сутки или неделю по каждой теме, без ИИ. Важность считается так: сколько независимых источников пишут, `weight` источника (официальные блоги = 2), теги «релиз»/«безопасность» и т.п. Кнопка «Скопировать текстом» даёт готовый список со ссылками, чтобы переслать.

**Обзор недели** — связный текст на русском в «Дайджесте» (ссылка сразу на него: `#review`). Пишется вручную через Claude Code по ленте и хранится в `site/data/weekly.json`; новый выпуск добавляется в начало списка `issues`, старые остаются в архиве.

**Темы по содержанию:** у смешанных источников (`auto_category` в `sources.json` — Hacker News, Ars, «Хабр — лучшее») тема определяется по тексту: безопасность → «IT и безопасность», ИИ-инструменты → «Инструменты», модели → «Модели ИИ». Теги и темы пересчитываются для всей ленты при каждом сборе.

**Связь с базой знаний:** у записей `kb.json` есть шаблон `match`; новости, где упоминается модель, инструмент или понятие, получают метку со ссылкой на запись (`#kb/Gemini`), а в карточке базы знаний — блок «Последние новости».

**Мои темы:** слова через запятую над лентой — такие новости подсвечиваются, есть фильтр «только они». Хранится в браузере.

**Telegram:** `scripts/telegram_post.py` после каждого сбора присылает главное (та же оценка важности, что в дайджесте) и новые обзоры недели. Нужны секреты репозитория `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (Settings → Secrets and variables → Actions); без них шаг пропускается. Отправленное помнится в `state/telegram.json`. Проверка без отправки: `python scripts/telegram_post.py --dry-run`.

**Оформление** — темы сайта: «Стандартная» и «Газета» (шрифты с засечками, колонки, передовица; есть ночной вариант). Выбор хранится в браузере, ссылка сразу на газетный вид: `?skin=paper`. Новая тема = запись в `SKINS` (`site/app.js`) + блок `:root[data-skin="…"]` в `site/styles.css`.

«Новое» — это всё, что появилось после вашего предыдущего визита. Избранное и тема хранятся в браузере у каждого пользователя.

## Локальный запуск

```bash
python scripts/fetch_news.py          # собрать свежие новости
python -m http.server 8000 -d site    # открыть http://localhost:8000
```

Если открыть `index.html` двойным кликом, браузер не даст загрузить JSON, поэтому нужен локальный сервер.

## Первая настройка GitHub Pages (один раз)

1. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. **Actions → Update news & deploy → Run workflow** запускает первую сборку вручную.
3. Сайт будет доступен по адресу `https://<user>.github.io/AiNews/`.

## Как дополнять

- **Новый источник:** добавьте строку в `sources.json`. Нужна ссылка на RSS/Atom; для релизов GitHub подходит `https://github.com/<owner>/<repo>/releases.atom`.
- **База знаний:** отредактируйте `site/data/kb.json` (разделы `models`, `tools`, `concepts`).
- **Теги:** правила лежат в `TAG_RULES` в `scripts/fetch_news.py`.
- **Срок хранения:** по умолчанию 45 дней, для отдельного источника — `keep_days` в `sources.json` (arXiv — 14 дней).
- **Чистка описаний:** служебный текст фидов (arXiv, Hacker News, «Читать далее» Хабра) убирается в `tidy()`; у Hacker News сохраняются рейтинг и число комментариев.
